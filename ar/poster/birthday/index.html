Poster AR WebM Rigour Package v11

Run these tests in order. This version uses assets/animation_v01.webm and supports a larger transparent WebM canvas extending beyond the tracked poster.

1. System Diagnostics

Open diagnostics.html

Checks HTTPS, camera API, imports, required files, and WebM support.

2. Tracking Only

Open tracking-test.html

Shows a cyan square when the poster target is recognised.

3. Overlay Alignment

Open overlay-test.html

Shows poster-opening-frame_v01.png on the recognised target.

4. WebM Video Texture Test

Open webm-video-test.html

Plays animation_v01.webm as a video texture after recognition, including overscan beyond the poster bounds.

5. Full Experience

Open full-experience-webm.html

Starts with poster overlay, then swaps to WebM animation on recognition.

Expected files

targets.mind
assets/poster-opening-frame_v01.png
assets/animation_v01.webm
